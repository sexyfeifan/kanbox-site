Kanbox 隐私说明

Coming Soon · Kanbox 尚未正式上线，以下为当前开发版本的隐私说明。

以下 App 说明与当前项目内置政策一致。网站数据说明单独列于文末。

更新日期：2026年10月2日

本机收藏与个人资料

KanBox 用于保存链接、图片、视频、标签和灵感笔记。收藏、搜索历史、偏好、昵称与头像主要保存在设备上。当前版本未接入广告或第三方用户行为分析 SDK，未设置开发者接收收藏内容的业务服务器，不用于跨应用广告追踪。

网络访问与第三方平台

解析链接、加载远程图片及播放媒体会向链接对应的平台或其内容服务器发起请求。对方可能收到你的 IP 地址、请求的链接、浏览器标识等网络信息，并按其自身政策处理。部分平台解析会使用 WebKit 与网站 Cookie；访问受登录限制的内容可能涉及已有网站会话。KanBox 不要求你将平台密码交给开发者。不保证第三方平台不收集网络访问数据。

小红书作者订阅使用独立的本机 WebKit 网站资料区保存登录 Cookie 与网站存储，关闭作者页或重启 App 后可复用尚未过期的登录；平台要求验证或会话过期时需重新登录。登录资料不纳入 KanBox 的导出备份、分享扩展或收藏 iCloud 同步，也不发送给开发者。来源列表与正文预览只作临时查看，不自动进入收藏库或离线下载。你可在作者页或“设置 → 隐私与权限”退出 KanBox 内的小红书登录，清除该资料区及临时预览；此操作不删除收藏或订阅，不影响小红书 App 的登录。清空收藏不等于退出网站登录。系统整机备份由 iOS 管理。

剪贴板

“设置 → 收藏设置”的“检测剪贴板链接”开关开启时，App 回到前台会检测剪贴板中可能的链接并显示确认提示；只有你右滑或点击收录后才解析并保存，左滑或点击忽略不会收录。关闭此开关后不再进行前台自动检测；你仍可主动粘贴或通过系统分享收录。解析时链接会发给对应内容平台，不会发给开发者业务服务器。

iCloud 与扩展

当系统诊断显示使用 iCloud 数据库时，收藏及笔记会通过 Apple CloudKit 同步到你的 iCloud 账户；未启用或不可用时保存在本机。分享扩展、小组件与主 App 通过 App Group 共享待导入内容、偏好和收藏快照；小组件可能显示收藏标题和封面，请注意桌面可见性。离线视频副本保存在当前设备，不随收藏数据库同步。

相册、相机与导出

相机用于你主动拍摄笔记图片；保存媒体到相册时请求相册写入权限。拒绝这些权限不影响基本收藏功能。你主动导出备份、生成分享图或使用系统分享面板时，选中的内容会交给你选择的应用或保存位置，其处理方式由该接收方决定。

保存期限与删除

收藏保留至你主动删除；可在设置中导出备份或清空本机数据。图片缓存可能自动清理，离线视频可单独移除。缓存清理不等于删除收藏。系统相册、外部备份和接收方持有的副本需在对应位置删除。iCloud 模式下删除同步记录可能传播到其他设备；iCloud 中的历史备份和系统保留内容由 Apple 管理。撤销系统权限不会自动删除已保存内容。

控制与政策更新

你可在 App 设置关闭剪贴板检测、退出 KanBox 内的小红书登录，并在 iOS 设置管理相机、相册和 iCloud 权限。政策随版本变化更新；新增开发者服务器、统计或广告前须重新告知并更新声明。

本介绍网站

本网站由 GitHub Pages 托管，未添加广告、第三方用户行为分析、表单或登录功能。收录、分类与回顾示例在当前页面内运行，不向服务器提交示例操作或保存个人收藏。

GitHub 会为安全目的记录网站访问者的 IP 地址，详见 GitHub 隐私声明。点击网站源码或反馈链接后，将进入 GitHub，并适用其数据处理政策。

反馈与联系

可通过 Kanbox 网站反馈入口 联系维护者。GitHub Issue 默认公开，请勿在其中提供私人收藏、网站登录信息或其他敏感数据。
